# LOS SANTOS HEIST — «Ограбление склада»

Браузерная 3D-игра в духе GTA V на **Three.js r128**: открытый город, вид от третьего лица,
вождение, стрельба, ИИ охраны и полиции — и одна полностью законченная сюжетная миссия
с брифингом, боем, захватом груза, погоней и экраном итогов.

Никаких сборщиков, серверов и внешних CDN: библиотека лежит в `vendor/`,
все текстуры, звуки и модели генерируются кодом.

```
git clone <репозиторий>
# просто откройте файл в браузере:
xdg-open index.html      # Linux
open index.html          # macOS
start index.html         # Windows
```

Если браузер запрещает локальные файлы (редко — зависит от политики), поднимите любой
статический сервер: `python3 -m http.server 8000` и откройте `http://localhost:8000/`.

## Миссия «Ограбление склада»

Конечный автомат `BRIEFING → DRIVE → COMBAT → GRAB → EXTRACT → SUCCESS/FAILED`
(`src/mission.js`):

1. **Брифинг** — текстовый экран с задачей и управлением.
2. **Старт** — игрок появляется рядом с машиной на главной магистрали; цель подсвечена
   маркером на миникарте, GPS-стрелкой и столбом света в мире.
3. **Проезд к цели** — ~350 м до промзоны на юго-востоке.
4. **Боевой эпизод** — пятеро вооружённых охранников: трое патрулируют двор,
   двое внутри ангара. Счётчик целей в HUD обновляется в реальном времени.
5. **Захват груза** — после зачистки в ангаре появляется светящийся кейс; подбор при подходе.
6. **Погоня** — сразу выставляется 2 звезды розыска, к игроку выезжают патрульные машины
   (до 4 одновременно), из остановившихся выходят копы. За убийство полицейского розыск растёт.
7. **Эвакуация** — доехать до порта на северо-западе (11 м до центра зоны).
8. **Итоги** — «Миссия пройдена» со статистикой (время, убийства, точность, урон,
   состояние машины, розыск) либо «Миссия провалена» при нулевом здоровье — с рестартом
   без перезагрузки страницы.

## Структура кода

| Файл | Ответственность |
|---|---|
| `index.html` | HTML-оверлей HUD, экраны (брифинг/пауза/итоги), подключение скриптов |
| `src/core.js` | утилиты, ввод (клавиатура/мышь/pointer lock), синтез звука (Web Audio), рендерер, небо, свет, постобработка, процедурные текстуры |
| `src/fx.js` | пулы частиц: искры, дым, пыль из-под колёс, трассеры, вспышки, тряска камеры |
| `src/world.js` | генерация города, промзоны и порта; физический мир (AABB + broadphase-сетка), выталкивание кругов, лучевые проверки |
| `src/character.js` | low-poly риг персонажа из примитивов и процедурная анимация (покой/бег/прицел/посадка/смерть) |
| `src/player.js` | движение, стрельба, здоровье, посадка в транспорт, камера от третьего лица |
| `src/vehicle.js` | аркадная физика машины, крены, деформация кузова, ИИ полицейских машин |
| `src/npc.js` | ИИ охраны и копов (патруль → подозрение → бой), попадания по капсуле/голове |
| `src/hud.js` | здоровье, звёзды розыска, патроны, миникарта (2D canvas), GPS, уведомления |
| `src/mission.js` | сценарий миссии, маркеры, уровень розыска, статистика |
| `src/main.js` | сборка, главный цикл, экраны, рестарт, отладочные хелперы |
| `vendor/three/` | Three.js r128 + EffectComposer/UnrealBloom/FXAA (examples/js) |

### Отладка (консоль браузера)

## Что под капотом

**Город.** Сетка дорог с шагом 100 м на площади 800×800 м, 60+ кварталов, главная
магистраль `z = 0`, тротуары-бордюры, парки с деревьями, фонари, светофоры, разметка.
Здания — 10 прототипов с процедурными текстурами фасадов (часть окон «горит»),
рисуются `InstancedMesh` (по одному вызову на прототип). Фонари, деревья, светофоры,
припаркованные машины — тоже инстансинг (у машин цвет кузова задаётся `setColorAt`).
После оптимизации в сцене ~130 обычных мешей и 35 `InstancedMesh` на 1700+ объектов.

**Физика.** Специализированная, без внешнего движка:
* персонажи — круг радиуса 0.45 м, выталкивание из AABB со скольжением вдоль стен;
* машина — «велосипедная» модель (тяга, сопротивление, угол поворота, зависящий
  от скорости, сцепление, занос на ручнике), пять контактных кругов, момент от удара
  в угол, отражение скорости, накопление повреждений;
* пули и линия взгляда — свой `ray↔AABB` (метод слэбов) поверх broadphase-сетки,
  попадания по NPC — `ray↔цилиндр` (корпус) и `ray↔сфера` (голова, ×3 урона).

**Деформация кузова.** Геометрия кузова сегментирована; при ударе вершины рядом с точкой
контакта смещаются внутрь (с ограничением 0.42 м) и нормали пересчитываются — вмятины видны
и остаются до рестарта. При 100 единицах урона двигатель глохнет, из-под капота идёт дым.

**ИИ.** Охрана патрулирует точки, замечает игрока по дистанции, углу обзора и прямой
видимости, поднимает тревогу у соседей в радиусе 55 м, держит дистанцию ~13 м, стреляет
очередями с перезарядкой и разбросом, теряет игрока и идёт к последней известной позиции.
Полицейские машины едут к игроку с объездом препятствий по трём пробным лучам.

**Графика.** `ACESFilmicToneMapping`, sRGB, PBR-материалы, тени `PCFSoftShadowMap` с картой
2048², «едущей» за игроком, градиентное небо с солнечным диском в шейдере, туман,
`EffectComposer`: bloom → радиальный скоростной блюр с виньеткой (усиливается от скорости) → FXAA.
За время миссии солнце медленно садится: свет и небо теплеют, зажигаются окна и фонари.

**Звук.** Полностью синтезирован в Web Audio: мотор (две пилы + фильтр, частота от оборотов),
выстрелы игрока и врагов, удары, сирена (LFO по частоте), интерфейсные сигналы.
Никаких аудиофайлов.

## Технические компромиссы (и как их снять)

| Компромисс | Почему | Как улучшить |
|---|---|---|
| Собственная аркадная физика вместо Cannon-es/Ammo | физический движок в UMD-сборке без модулей тянет ~200–700 КБ и решает задачу «одной машины» хуже специализированной модели; занос и удары настраиваются напрямую | подключить `cannon-es` (ESM + `<script type="module">` или сборщик), `RaycastVehicle` для подвески, настоящие compound-коллайдеры, рэгдолл вместо анимации падения |
| Персонажи собраны из боксов, анимация процедурная | нет доступа к риггованным ассетам; GLTF-модели требуют внешних файлов и лицензии | загрузить GLTF со скелетом (`GLTFLoader` + `AnimationMixer`), смешивать клипы idle/walk/run/aim/enter-car |
| Коллизии мира — только AABB (без поворотов) | быстрая broadphase-сетка и простые устойчивые ответы; здания всё равно прямоугольные | OBB/выпуклые оболочки или BVH (`three-mesh-bvh`) для точных попаданий по геометрии |
| Нет стрельбы из машины (drive-by) | камера и прицел в машине отвязаны от оружия | добавить режим бокового прицела: луч из окна, ограничение угла, анимация руки |
| Трафик и пешеходы отсутствуют, машины на обочинах статичны | десятки активных агентов съедают кадр, а для миссии они не нужны | сетка путей (waypoint graph) по дорогам, машины-агенты с follow-the-leader и светофорами |
| SSAO не включён | полноэкранный SSAO в браузере стоит 3–6 мс и конфликтует с прозрачностью | `SSAOPass`/`GTAOPass` на половинном разрешении либо запечённое AO в текстурах |
| Тени только от одного направленного источника, карта 2048² | компромисс качество/скорость | каскадные тени (CSM), отдельная карта для ближней зоны |
| Урон и «розыск» упрощены (нет системы укрытий, авторемонта, потери розыска) | миссия короткая и линейная | добавить укрытия для ИИ (cover points), затухание розыска вне зоны видимости, ремонт в гараже |
| Звук синтетический | без ассетов и лицензий | заменить на семплы (`PositionalAudio`), добавить эхо/реверб в помещении |
| Загрузка города — синхронная (~0.3–0.6 с) | проще и предсказуемее | генерация по чанкам в `requestIdleCallback` или в Worker с `transferable` |

**Производительность.** Целевые 60 FPS на средней дискретной/встроенной графике
достигаются за счёт инстансинга, тумана (дальность прорисовки 560 м), одного источника
теней, пулов частиц без аллокаций и ограничения `devicePixelRatio` до 1.75.
Если кадр проседает: уменьшите `sun.shadow.mapSize`, отключите `UnrealBloomPass`
или снизьте `renderer.setPixelRatio` в `src/core.js`.
